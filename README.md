# Java Weather Console Application 

A console-based Java application that retrieves real-time weather information using a public weather API. Users can enter a city name to view the current temperature, humidity, and wind speed.

## Features

- Real-time weather data fetching
- User input for city/location
- Displays:
  - Temperature
  - Humidity
  - Wind speed

## Technologies Used

- Java
- HTTP Requests
- JSON Parsing (`org.json` library)
- OpenWeatherMap API (or similar)
